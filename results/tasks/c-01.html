## What I built

- **`app.py`** — the service, using only the Python standard library (`http.server` + `sqlite3`), so there are zero dependencies to install.
- **`run.sh`** — executable; finds a Python 3 interpreter and runs the server in the foreground. `bash run.sh` is all it takes.

## Design choices

- **Storage:** SQLite (`data.db` next to `app.py`). Real on-disk datastore — survives restarts, never re-seeds. Schema is created with `CREATE TABLE IF NOT EXISTS` on startup.
- **Cascade:** enforced at the DB level via `FOREIGN KEY ... ON DELETE CASCADE` with `PRAGMA foreign_keys = ON`, so deleting an application removes its notes.
- **Port:** reads `PORT`, defaults to `8000`.
