# Code of Conduct

## The short version

Be decent. Argue about the work, not the person.

This project is a benchmark, so disagreement is the point — challenging a grade, a rubric, a
task's fairness, or a conclusion on the site is *contributing*, not attacking. Bring
evidence: every run's transcript is published so claims can be settled by looking.

## Not acceptable

Harassment, personal attacks, demeaning comments, or unwelcome attention. Publishing others'
private information. Sustained disruption. Deliberately submitting tasks or data designed to
game the benchmark rather than measure something.

## Scope

Applies in issues, pull requests, discussions, and anywhere someone is representing the project.

## Reporting

Report privately through
[GitHub's private reporting](https://github.com/helenatan/builder-bench/security/advisories/new),
or by direct message to the maintainer. Reports are handled confidentially.

The maintainer reviews all contributions and may edit, lock, or remove contributions that don't
follow this document, and block repeat offenders. This is a one-person project with lightweight
governance — there's no committee, just a maintainer trying to keep it a place worth
contributing to.
